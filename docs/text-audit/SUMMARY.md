## WEB-LAYOUT-RULES との主な差分・要確認

### トップカード（`works.md`）

- `.card h2` に `max-width: 62%`、`.card .lead` に `max-width: 64%` が指定されています。  
  モック画像とのレイアウト用ですが、**見出し・リードが意図的に狭い**状態です。
- 見出しは HTML 上 `<br>` なしの1行テキストのため、**スマホでは「報告書と」「聞いてみる」などで折り返し**が発生します（各 MD の「改行（innerText）」参照）。

### ストーリー LP（各 `demo-*.md`）

- `.story-preview-card h3` に `max-width: 220px` — プレビューカード見出しが固定で狭い。
- `@media (min-width: 701px)` で `.story-hero h1 br` / `.story-intro br` を **非表示** — PC では `<br>` による意図改行が消え、1行に連結されます（モバイルと見出しの切れ目が異なる）。
- `.story-meta` に `max-width: 540px`（701px 以上）— メタ情報ブロックのみ幅制限。

### 日本語折り返し（lp-japanese-wrap ルール）

- ストーリー hero の `<br>` 改行はモバイルで有効（例: 「現場写真から、」＋改行＋「報告書まで。」）。
- トップカード見出しは **読点・意味区切りを `<br>` で持たず** CSS 折り返し任せのため、orphan 風の行分割リスクがあります。

### 誤検知しやすい項目

- ヘッダー `.count`（`max-width: 160px`）は **件数バッジ用** で、本文ルールの対象外に近い。
- orphan 検出はヒューリスティックのため、「AXEON株式会社」など **1行で収まる短文** もフラグされることがあります。MD 内の ⚠ は目視確認用です。

## 次のアクション案（必要なら）

1. トップカード見出しを **配列 + `<br>`** または意味の切れ目で行分割（lp-japanese-wrap 準拠）。
2. ストーリー PC 向け `br { display: none }` の見直し（PC でも意図した行区切りを維持するか検討）。
3. `.story-preview-card h3` の `max-width: 220px` を撤去またはモバイルのみに限定。
