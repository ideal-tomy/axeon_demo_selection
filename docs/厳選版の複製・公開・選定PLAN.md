# AXEON_pf 厳選版の複製・公開・選定PLAN

作成日：2026-09-20  
状態：フェーズ1・2完了。フェーズ3は掲載10件と各層の役割を確定（`docs/phase3-selection-draft.md`）。完成大枠は `docs/selection-completion-plan.md`。カード差し替え・デモ改修は未実施。厳選版は https://axeon-demo-selection.vercel.app で公開済み（検証用・当面は複製内容のまま）。

## 1. 目的と確定方針

現在の `AXEON_pf` は、全件を閲覧できる一覧版としてそのまま残す。
別プロジェクトへ同じ状態で複製し、別の公開先へデプロイした後に、掲載する5〜10件を検討する。

厳選版は名刺裏面のQRコードやURL共有から案内する、自社の技術・商材・開発紹介サイトとする。カード形式のトップと、アプリ紹介のような詳細ページから実際のデモへ進む体験を活かす。

**作業順序は「同じ状態で複製 → 別デプロイ → 同等性確認 → 厳選内容の検討 → 改善・構成変更」とする。複製と同時に選定や削減を行わない。**

## 2. プロジェクトの役割

| 項目 | 既存の一覧版 | 新しい厳選版 |
|---|---|---|
| ローカル | `C:/Users/ryoji/00myapp/ai_demo_workspace/AXEON_pf` | `C:/Users/ryoji/00myapp/ai_demo_workspace/axeon_demo_selection` |
| 役割 | 全件カタログとして維持 | 名刺・URL共有から案内する紹介サイト |
| 初回の内容 | 現状維持 | 既存版と同じ内容・構成 |
| 選定後の内容 | 現状の一覧を維持 | 厳選した5〜10件 |
| デプロイ | 現在の公開先を維持 | 独立した新規プロジェクト・公開URL |

当面は独立したコピーとして管理し、共通パッケージ化やデータ同期の仕組みは作らない。厳選版を変更しても既存版に影響しないことを優先する。

紹介サイトの複製と、リンク先のデモ本体の複製は別の作業とする。初回は既存と同じ外部デモURLを使用する。後でデモ本体を改修する場合は、一覧版からも同じデモにアクセスすることを踏まえ、共通改善か別版作成かを個別に判断する。

## 6. フェーズ4：選定後に厳選版を仕上げる

層の役割の正本は [phase3-selection-draft.md](phase3-selection-draft.md)。  
10件の流れを通す完成までの大枠は [selection-completion-plan.md](selection-completion-plan.md)。個別の実装PLANはそこから都度切る。

### サイト構成

- トップに、納品線に届いた掲載分を現行のカード形式で並べる（最大10件。準備中は出さない）。
- カードから現行の詳細（紹介ページ）へ進み、外部デモへ行きたくなる状態にする。
- 外部デモは別タブ。戻ってカード一覧に戻れる導線を、付けられるものから付ける。
- 体験後の訴求が効くデモだけ LP を足す。LP からデモへ戻れるようにする。建設は LP を作らない。
- 全件一覧ページと業種検索など、一覧へ進むための導線を厳選版から外す。
- 関連デモは確定10件の範囲に揃える。
- 掲載対象外の詳細URLを開いた際の案内を決める。

### デモと紹介の仕上げ

- 代表（建設）で「カード → 紹介ページ → 外部デモ → 相談」の完成形を作る。
- 同じ基準で残りの掲載候補を1本ずつ仕上げる。
- デモは説明資料にせず、納品された画面のイメージが浮かぶ操作にする。
- 固定サンプル、保存範囲、利用条件は紹介ページに短く置く。
- 相談先と会社サイトへのリンクを実際に利用できる状態にする。

### 完了条件

- 掲載するデモが、紹介ページと外部デモの役割分担を満たす。
- 紹介から体験、必要なデモでは LP、相談までの導線が機能する。
- 一覧版の内容と公開先は維持されている。
