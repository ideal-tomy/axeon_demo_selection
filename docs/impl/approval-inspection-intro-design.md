## 4問

1. **何を見せ切るか**  
   図面と材料証明書を照合し、一致・要確認・記載なしに分ける。人が見る項目だけが保留に残り、確認根拠を承認記録に残してから、不足を検査基準へ戻す。

2. **本物の画面か**  
   検査担当の同一PC。照合、保留一覧、承認記録、基準改定。デモ本体の4タブと同じ案件（S-204 / B-310）。

3. **1人の段階か、複数人か**  
   型B。一人の検査担当が、照合 → 保留 → 承認 → 基準改定と進む。端末の種類は1つ。山田太郎は記録上の確認者であり、別端末は出さない。

4. **カメラは左から右へ進むか**  
   左＝照合、その右＝保留、その右＝承認、右端＝基準改定。戻らない。同時に光るのは最大2枚。

## 型

B（段階遷移）。4タブは別画面ではなく、同じ担当・同じ端末の前後状態として左から右へ置く。

## 見せ切る操作

照合で差分を分ける → 要確認だけ残す → 根拠付きで承認する → ロット番号を必須化する。
