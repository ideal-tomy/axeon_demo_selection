## 4問

1. **何を見せ切るか**  
   届いた依頼を開き、依頼文の日付を根拠で確認し、確定後に申請と人員の準備が並ぶ。提出・配置依頼はしない。

2. **本物の画面か**  
   現場ダンドリの同一PC。依頼一覧、段取り案（取り込んだ現場情報）、申請と人員の準備。渋谷区道玄坂2丁目、北関東電設のメール。

3. **1人の段階か、複数人か**  
   型B。一人の手配担当が、一覧 → 段取り案 → 準備と進む。端末の種類は1つ。田村は依頼元であり、別端末は出さない。

4. **カメラは左から右へ進むか**  
   左＝依頼一覧、中央＝段取り案、右＝申請準備。根拠モーダルは段取り案の焦点移動。戻らない。同時に光るのは最大2枚。

## 型

B（段階遷移）。3画面は別担当ではなく、同じ手配の仕事として左から右へ置く。

## 見せ切る操作

依頼を開く → 日付の根拠を見る → 申請と人員の準備が並ぶ（提出しない）。
