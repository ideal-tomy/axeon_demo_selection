# wholesale-quote 紹介 設計メモ

掲載：厳選版詳細ページのみ（`?embed=intro`）。デモ本体の `/desk` と `/lp` には置かない。

## 4問

1. **何を見せ切るか**  
   届いた型番の問い合わせを開き、確認結果と返信下書きが並ぶ。在庫表の該当行を見てから、返す内容は人が決める。送信はしない。

2. **本物の画面か**  
   営業の問い合わせ机。一覧、詳細（確認結果・下書き）、在庫表モーダル。同一担当のPC。

3. **1人の段階か、複数人か**  
   型B。一人の営業が、一覧 → 下書き → 根拠の表 → 返す、と進む。端末の種類は1つ。

4. **カメラは左から右へ進むか**  
   左＝今日の一覧、右＝問い合わせ詳細。在庫表は詳細の上に開く（同じ画面の焦点移動）。戻らない。同時に光るのは最大2枚。

## 型

B（段階遷移）。在庫表は別端末ではなく、詳細画面の根拠表示。

## 見せ切る操作

問い合わせを開く → 確認結果と下書き → 在庫表の該当行 → 下書きのまま返す（送信しない）。
