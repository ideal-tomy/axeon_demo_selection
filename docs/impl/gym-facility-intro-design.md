## 4問

1. **何を見せ切るか**  
   今日の利用可否と要対応を見渡し、設備の記録の線（非常用発電機 K-G3）を開き、画像で対応の要否を残す。送信・本番保管はしない。

2. **本物の画面か**  
   指定管理者の同一PCコンソール。施設の状況、場所・設備一覧（カルテ）、画像確認。翠嶺市総合体育館。INC-20260912-007。

3. **1人の段階か、複数人か**  
   型B。一人の施設担当が、状況 → カルテ → 画像確認と進む。端末の種類は1つ。岡田・高木は記録上の確認者であり、別端末は出さない。

4. **カメラは左から右へ進むか**  
   左＝施設の状況、中央＝場所・設備、右＝画像確認。カルテの引き出しは同じ画面の焦点移動。戻らない。同時に光るのは最大2枚。

## 型

B（段階遷移）。3画面は別担当ではなく、同じ指定管理の仕事として左から右へ置く。

## 見せ切る操作

状況で要対応を見る → 発電機の記録の線を開く → 画像で「対応が必要」を残す（送信しない）。
