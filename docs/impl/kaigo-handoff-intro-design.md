## 4問

1. **何を見せ切るか**  
   時刻枠の録音が申し送り欄に積もり、要確認は人が直してから出す。面談は会話が経過記録になり、日報は確認すると欄が埋まる。

2. **本物の画面か**  
   職員スマホの同一アプリ。申し送り（クリップ＋SummaryCard）、面談（RecHud→KarteSummaryCard）、日報（確認待ち＋フロアカード）。フィクスチャはデモ本体と同じ田中さん。

3. **1人の段階か、複数人か**  
   型B。同じ職員の仕事が、申し送り → 面談 → 日報と進む。端末の種類は1つ。

4. **カメラは左から右へ進むか**  
   左＝申し送り、中央＝面談、右＝日報。戻らない。同時に光るのは最大2枚。

## 型

B（段階遷移）。3つの記録は別タブだが、同じ職員・同じ端末の仕事として左から右へ置く。

## 見せ切る操作

録音（10:00）→ 投薬の要確認 → 面談の会話が欄になる → 日報の確認待ち → 確認後に欄が揃う。
