# dd-ma 紹介 設計メモ

掲載：厳選版詳細ページのみ（`?embed=intro`）。デモ本体の `/` と `/ai` には置かない。自社入力・ライブ給与・API診断は出さない。

`/` はバニラの4フェーズ画面、代表3手は `/ai` の同一コンソールにある。embed は `/?embed=intro` を `/ai.html` へ寄せて、EXIT試算の実画面だけを返す。

## 4問

1. **何を見せ切るか**  
   サンプル企業のEXIT試算を見渡し、主軸を切り替えて株式価値と簿外処置が動くのを見る。判断の問いと返した時間が残る。提出・提案更新はしない。

2. **本物の画面か**  
   `/ai` の同一PC。対象企業（東和ロジスティクス）、EXITダッシュボード（想定株式価値・ギャップ・主軸タブ・簿外処置）、判断の問いと返した時間。端末の種類は1つ。

3. **1人の段階か、複数人か**  
   型B。一人の買収・再生担当が、EXIT → 主軸切替 → 問いと時間 と進む。別担当・別端末は出さない。

4. **カメラは左から右へ進むか**  
   左＝EXIT、中央＝主軸切替、右＝問いと時間。簿外処置は主軸画面の焦点移動。戻らない。同時に光るのは最大2枚。

## 型

B（段階遷移）。3画面は別担当ではなく、同じ `/ai` コンソールの仕事として左から右へ置く。

## 見せ切る操作

EXITの株式価値を見る → 主軸を不採算整理に変えて処置が動く → 判断の問いと返した時間（提出しない）。
